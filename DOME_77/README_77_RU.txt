DOME 77 — полный backend для Railway.

Это цельная версия, а не patch. Ничего из старых папок в неё копировать не нужно.
Railway использует Dockerfile и railway.json из корня.
Переменные окружения (.env) в архив намеренно не включены: в существующем Railway service используются уже настроенные Variables.

Основные изменения 77:
- standalone регистрация по email/паролю;
- обязательное подтверждение email 6-значным кодом;
- повторная отправка кода;
- восстановление пароля по email;
- вход на новом устройстве по email/паролю;
- Telegram pairing больше не нужен;
- mobile API голос/изображения поддерживают JSON base64 и multipart;
- TTS/перевод и изменение языков через mobile API;
- сохранены уроки, герои, прогресс, 2 прохождения, мультфильмы, ДЗ, оплаты и email-отчёты v75.

Для отправки verification/password-reset писем в Railway должны быть заполнены существующие SMTP_* Variables.
