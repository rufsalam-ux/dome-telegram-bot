# DOME v27 — журнал активности

Добавлено:
- структурированные строки `ACTIVITY | {...}` в Railway Deploy Logs;
- имя ребёнка, Telegram ID, session ID, урок, слайд и шаг;
- события получения/оценки голосового ответа с transcript/status/language;
- события чемодана и выбранных предметов;
- начало/успех/ошибка рендера мультфильма;
- `/whoami` показывает Telegram ID;
- `/activity` показывает администратору последние 12 учебных сессий и последний голосовой ответ.

Для `/activity` добавьте в Railway Variables:
`ADMIN_TELEGRAM_IDS=ваш_telegram_id`
Можно указать несколько ID через запятую.

В Railway Logs удобно искать `ACTIVITY` или конкретное имя ребёнка.
