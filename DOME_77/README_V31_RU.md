# DOME v31 — живой диалог и адаптация внутри урока

Добавлен Conversation & Adaptation Engine.

Что изменилось:
- бот обращается к ребёнку по имени иногда, а не в каждой реплике;
- понятный «достаточно хороший» ответ больше не обязан автоматически повторяться;
- по умолчанию максимум одна мягкая поправка, затем одно упрощение/готовый вариант;
- фразы помощи звучат естественнее: «давай подумаем вместе», «хочешь, помогу?», «у меня есть вариант»;
- если бот предлагает помощь, он должен давать пригодный готовый вариант ответа;
- сложность обновляется во время урока по текущим ответам ребёнка;
- сильному ученику разрешены дополнительные вопросы/диалог;
- ребёнку, которому трудно, задание сокращается до короткой фразы или называния того, что он видит;
- параметры вынесены в `config/conversation.json` и редактируются из DOME Control Center без изменения Python.

Новая вкладка Control Center: **«Диалог и адаптация»**.

Важно: адаптация ограничена правилами текущего урока и не должна менять образовательную цель урока.
