# DOME v49 — архитектура полноценной анимации героя

Эта версия **закладывает расширяемую архитектуру** для настоящей персонажной анимации и сохраняет стабильный v48-рендер как fallback.

## Что предусмотрено
- rig персонажа: голова, корпус, руки, ноги, кисти, стопы, рот/глаза;
- ракурсы: front, 3/4 left/right, side left/right, back;
- lip-sync;
- библиотека примитивов: walk/run/turn/look/talk/wave/point/jump/sit/pick_up/dance/crawl и др.;
- составные движения из примитивов;
- возможность подключить AI motion provider без изменения уроков;
- новые уроки описывают движение через `actions` в timeline, поэтому новый ZIP для каждого движения не нужен;
- неизвестное действие должно сначала раскладываться motion planner-ом на базовые движения;
- при отсутствии rig/provider мультфильм не ломается: используется прежняя PNG-анимация.

## Важно
В v49 нет встроенной внешней AI-модели, которая сама генерирует недостающие ракурсы и скелет. Для **реального шевеления конечностями и настоящего lip-sync** нужен подключённый animation provider/rigging backend. Архитектура и интерфейс для него уже предусмотрены.
