# DOME v52 — localization, interactive animals, scheduling-ready

Что добавлено:
- Первая сцена героя с Лёшей: минимум 10 секунд. `timeline.json` поддерживает `description_ru`, `placement_ru` и нормализованные `position_hint`.
- Две интерактивные пары животных: пингвин+попугай и лев+черепаха. Правильный ответ подсвечивается/анимируется, звучат мягкие фанфары, бот произносит название животного на изучаемом языке. Новые пары намеренно не добавлены.
- Обязательные реплики мультфильма остаются отдельными и не пропускаются.
- Более тёплый эмоциональный TTS-профиль для малышей сохранён глобально.
- Визуальная локализация: если target=ru, изображения остаются как есть. Если target!=ru и есть OPENAI_API_KEY, русские надписи, встроенные в PNG/JPG, очищаются через Image Edit и заменяются на target language; результат кэшируется. При недоступности API урок не падает.
- Красивый финальный титр локализуется на изучаемый язык; для русского остаётся «Мультфильм озвучил/озвучила Имя».
- `lesson_reminders.py` хранит расписание в часовом поясе клиента и запрещает ночные напоминания.
- Домашнее задание остаётся частью `lesson.json` и отправляется после завершения урока существующим механизмом.
- Kling остаётся опциональным: без ключей используется стабильный PNG fallback.

Важно: автоматическая замена текста, уже запечённого внутрь базового MP4 мультфильма, требует либо координат текстовых зон/чистой видеобазы, либо отдельного video-inpainting сервиса. v52 локализует текстовые титры DOME и статические слайды автоматически; она не обещает надёжно стирать произвольную кириллицу из каждого кадра чужого MP4 без заранее заданных областей.
