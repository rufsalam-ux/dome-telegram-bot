# DOME v56 — State Machine Fix

Исправления по реальному тесту 10.08.2026:

- атомарный переход между слайдами: старые phrase/object/help/skip состояния очищаются до нового шага;
- required phrase проверяется на принадлежность текущему slide_id;
- чемодан после `Чемодан собран` не может откатиться назад; голос, пришедший в race-window, принимается как take_trip;
- максимум 3 голосовые попытки остаётся жёстким лимитом;
- animal compare теперь содержит две детерминированные задачи на пару, поэтому голосовые реплики проходят все 4 животных: parrot, penguin, lion, turtle;
- после выбора животного следующая реплика всегда про выбранное животное;
- отдельные повторные guided-слайды lion/parrot отключены, чтобы не мучить ребёнка повтором;
- картинки пары показываются в Telegram до открытия Mini App; Mini App блокирует карточку при ошибке загрузки изображения;
- короткая осмысленная фраза в контексте животного принимается без требования придумать лишнюю деталь;
- personal travel: одна инструкция — один ответ (просто назвать место);
- AI follow-up на этих шагах отключён;
- `next_slide` сценария имеет приоритет над соседним индексом массива;
- удалены визуальные слоговые разделители `·`;
- добавлен persistent translation cache для ускорения повторных известных текстов;
- сохранены v55: финальный титр MP4, text-overlay архитектура, новый penguin.png, TTS cache.
