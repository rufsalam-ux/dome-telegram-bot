# DOME v63 — фикc вечной сборки мультфильма

Исправлен критический финальный сценарий после сообщения «🎬 Собираю твой мультфильм…».

Что найдено:
- `content/lessons/demo_001/cartoon-base.mp4` в v62 имеет размер около 62 MB.
- fallback v62 просто копировал этот файл и затем пытался отправить его как Telegram video.
- сессия помечалась `COMPLETED` до подтверждения успешной отправки видео.
- при timeout `asyncio.to_thread()` рабочий поток мог продолжать писать в тот же output, куда одновременно писал fallback.

Что исправлено:
- любой MP4 больше 45 MB автоматически пережимается в Telegram-safe вариант;
- проверено на реальном 62 MB base: результат ~30 MB;
- primary render пишет в отдельный `.rendering.mp4`, поэтому поздний worker не может испортить fallback;
- добавлен timeout отправки Telegram;
- `COMPLETED` ставится только после успешной отправки мультфильма;
- при ошибке/timeout статус возвращается в `IN_PROGRESS`, ответы ребенка сохраняются и сборку можно повторить;
- добавлены диагностические этапы `MOVIE_START`, `RENDER_START`, `RENDER_DONE`, `FALLBACK_START`, `FALLBACK_DONE`, `UPLOAD_START`, `MOVIE_SENT`, `MOVIE_FAILED`, `MOVIE_COMPLETE`;
- добавлены regression tests для финальной доставки мультфильма.

Не менялись учебная логика, картинки, языки, голосовые задания и остальные функции v62.
