# DOME v67 — Universal Russian Lesson Engine

Основа: v66 CHITAYKA_AUO. В v67 сохранён разговорный урок и «Читайка 1», добавлена «Книжные истории · Встреча 1» и универсальная архитектура для следующих уроков без пересборки ZIP.

## Три курса
- Разговорная практика — речь, диалоги, герой ребёнка, персональный мультфильм.
- Читайка — буквы/звуки/слоги, обводка, письмо, короткое чтение.
- Книжные истории — ребёнок уже читает: чтение вслух и по ролям, мягкая помощь, вопросы и обсуждение.

## Доступ и тарифы
Тестовый режим: `billing_enabled=false`, поэтому уроки доступны без оплаты. Единые цены всех трёх курсов сохранены в persistent settings: 1×/нед €39, 2× €79, 3× €109, 4× €139. Каждый урок — максимум 2 завершённых прохождения, доступ до 10 месяцев. Возврат после обрыва не считается новым прохождением. В уроках с мультфильмом новый персональный мультфильм создаётся только при первом прохождении.

Админ-команды (работают только для `ADMIN_TELEGRAM_IDS`):
- `/dome_prices`
- `/dome_price 2 85` — поменять цену без ZIP/redeploy
- `/dome_billing off|on` — бесплатный тест / включить оплату

## Добавление уроков без ZIP
Админ может отправить боту:
`/addlesson reading reading_002 Название урока`
Далее бот запросит: 1) PDF/PPTX урока, 2) DOCX/PDF/TXT инструкции, 3) PDF/PPTX ДЗ. Материалы сохраняются в persistent `storage/authored-content/lessons`, поэтому не исчезают после deploy. Если настроен OpenAI API, импортёр визуально анализирует страницы пакетами, выбирает тип Mini App и для кликабельных сцен может предложить нормализованные hotspot-координаты; при сбое используется консервативный разбор инструкции. Создаётся черновик `active=false`; после проверки `/publishlesson lesson_id`.

`/lessonmap lesson_id` показывает карту типов заданий. `/slidetype lesson_id 25 tap_sound` меняет тип конкретного слайда без redeploy.

## Универсальный Mini App
Поддерживается библиотека: голос, повтор, диалог, roleplay, read_aloud, read_roles, echo/shared reading, comprehension, retell, continue_story, tap/multi-select, tap-to-sound, listen-and-choose, drag-drop, matching, visible matching, memory, sorting, sequence, word/syllable/sentence builder, fill-gap, odd-one-out, sound position, syllable split, find-in-text, connect-lines, trace, handwriting, draw/coloring, maze, dictation, video, interactive scene, photo/real-world task, physical activity, mood choice. Несколько педагогических типов переиспользуют один низкоуровневый renderer Mini App.

## Книжные истории · Встреча 1
Добавлены 97 страниц из предоставленного PDF, инструкция преподавателя и 8 страниц ДЗ. Инструкция сопоставлена со слайдами: чтение вслух, чтение по ролям и вопросы/обсуждение. При трудностях чтения бот ограничивает навязчивые коррекции; после повторных затруднений берёт фрагмент на себя. Цель занятия 35 минут, диапазон 30–40 минут.

## Читайка · А, У, О
Сохранены 28 слайдов v66: мультфильмы на 3 и 11, дорожка букв А/У, письмо/обводка, tap-to-hear, открытые пары. Добавлено 3-страничное интерактивное ДЗ: ребёнок пишет/обводит/рисует поверх страницы.

## ДЗ родителю
После authored-урока ДЗ открывается ребёнку в боте. Если у родителя включены email-отчёты и настроен SMTP, письмо с ДЗ отправляется на email; исходный PDF прикладывается, когда он есть.

## Важно
`Proof of Learning` в v67 намеренно НЕ включён: это отдельный продукт.

Для PPTX-импорта Docker устанавливает `libreoffice-impress`; для PDF — PyMuPDF. Для сохранения импортированных уроков и настроек Railway должен использовать persistent volume для `STORAGE_ROOT`/базы, как и раньше.
