# DOME v69 — FINAL ARCHITECTURE FIXES

Основано на v68. Эта версия закрывает найденные после критического аудита архитектурные пробелы именно DOME-бота с тремя курсами. Она не относится к боту публикаций Telegram-канала.

## Что исправлено

1. **Тариф 1/2/3/4 урока в неделю теперь реально управляет выдачей.**
   - Берётся `Subscription.lessons_per_week` конкретного ребёнка.
   - Первая недельная квота открывается сразу после старта подписки.
   - Следующая квота — каждые 7 дней.
   - Отмена подписки останавливает только будущую выдачу; уже открытые уроки не отбираются.
   - Срок 10 месяцев считается с `unlocked_at` конкретного урока.

2. **Бесплатный тестовый режим сохранён.**
   Пока `billing_enabled=false`, опубликованные уроки можно тестировать без оплаты. Для тестирования реальной недельной логики есть `/dome_testplan child_id course_id 1|2|3|4`.

3. **Новый урок загружается без нового ZIP.**
   `/addlesson` теперь принимает 4 блока: основной урок → инструкция → ДЗ → дополнительные материалы/ссылки. На последнем шаге можно присылать несколько видео/файлов и ссылки вида `слайд 3 https://...`, затем `/done_extras`.

4. **Инструкция разбирается устойчивее.**
   Поддержаны формы `3 слайд`, `Слайд 3`, нумерованные пункты и таблицы DOCX. При наличии OpenAI выполняется дополнительная AI-привязка всей инструкции к страницам; regex остаётся fallback.

5. **Строгая валидация перед публикацией.**
   `/validate_lesson lesson_id` проверяет урок и ДЗ. `/publishlesson` блокируется, если drag/drop, matching, reading, interactive_scene и другие задания не имеют необходимых данных.

6. **Предпросмотр без расхода прохождения.**
   `/previewlesson lesson_id` запускает урок как ребёнок, но не списывает 1 из 2 прохождений, не выдаёт ДЗ и не создаёт мультфильм.

7. **Версии и rollback уроков.**
   Перед изменениями и публикацией создаётся snapshot. Команды: `/lessonversions lesson_id`, `/lessonrestore lesson_id version_name`.

8. **Mini App расширен.**
   Отдельно обрабатываются connect-lines, coloring, maze, dictation, interactive_scene, sound_position, syllable_split; базовые drawing/trace остаются общим универсальным canvas там, где это педагогически нормально.

9. **Видео с паузой и вопросом.**
   `video_pause_question` открывается в Mini App, может остановить YouTube/direct video на `pause_at_seconds`, показать вопрос/варианты и вернуть результат в урок.

10. **Чтение по ролям усилено.**
    Поддерживаются ordered `role_turns`. Бот озвучивает свои роли, ребёнок читает свои; при затруднениях `reading_child_share` уменьшается, при уверенном чтении постепенно растёт.

11. **Единые правила доступа у всех встроенных уроков.**
    `max_completed_runs=2`, `expires_after_months=10`; для разговорного курса мультфильм создаётся только в первом прохождении.

12. **Stripe lifecycle усилен.**
    Поддерживаются checkout completion, successful invoice, failed invoice, subscription update/cancel/pause. Webhook events идемпотентны через отдельную таблицу. При failed payment уже открытые уроки не удаляются, но новые weekly releases останавливаются до восстановления статуса.

13. **Хранилище DOME не смешивается с ботом канала.**
    DOME больше не выбирает `/data` автоматически только потому, что такой mount существует. Для DOME persistent storage задаётся явно через `STORAGE_ROOT` или `DATA_DIR`, если это потребуется на его Railway-сервисе.

## Рабочий процесс добавления следующего урока

`/addlesson reading lesson_002 Название` → основной PDF/PPTX → инструкция → ДЗ → дополнительные материалы/ссылки → `/done_extras` → `/lessonmap` → `/hwmap` → `/validate_lesson` → `/previewlesson` → при необходимости `/slidetype`, `/slideconfig`, `/hwtype`, `/hwconfig` → `/publishlesson`.

Обычное добавление новых уроков после этого не требует GitHub/ZIP/redeploy. Новый ZIP понадобится только если в будущем потребуется принципиально новый технический тип механики, которого нет в универсальной библиотеке.
