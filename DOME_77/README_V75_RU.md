# DOME v75 — Conversation Only Safe Mode

Временная production-сборка по решению владельца.

- Клиентам доступен только курс `conversation`.
- `learn_to_read` (Читайка) и `reading` (Книжные истории) скрыты и заблокированы.
- Смена курса и переходы между курсами отключены.
- Автоматические переходы и повтор всего курса через transition-engine отключены. Второе прохождение отдельного разговорного урока по-прежнему остаётся доступно по обычным правилам.
- Разговорный курс сохраняет прежнюю логику персонального мультфильма после первого полного прохождения.
- Контент и прогресс отключённых курсов не удаляются, чтобы их можно было вернуть позже.
- Старые callback-кнопки отключённых курсов отклоняются сервером.
