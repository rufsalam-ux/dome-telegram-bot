# Как менять уроки DOME без программирования

Главная папка уроков: `DOME_77/content/lessons`.

Текущий урок про Мадагаскар и Исландию находится здесь:

`DOME_77/content/lessons/demo_001/lesson.json`

Картинки этого урока лежат в папке `demo_001/lesson-images`. Новые короткие видео кладите в `demo_001/videos`, аудио — в `demo_001/audio`.

Перед любой правкой скопируйте `lesson.json` рядом и назовите копию, например `lesson-backup-31-08.json`. Меняйте только текст внутри кавычек и целые блоки между `{` и `}`. Запятая между соседними блоками обязательна.

После каждой правки откройте PowerShell в папке `DOME_MOBILE_77` и выполните:

```powershell
npm run validate-lessons
```

Если всё правильно, последняя строка будет: `ВСЕ УРОКИ ПРОШЛИ ПРОВЕРКУ.`

## Как устроен урок

Внутри `lesson.json` найдите строку `"slides": [` — это порядок шагов урока. В DOME слово `slide` означает любой шаг: картинку, вопрос, выбор, перетаскивание, отдых или видео.

У каждого шага есть уникальное имя `slide_id` (или короткое `id`). Не давайте двум шагам одинаковое имя.

В текущем уроке переходы задаются строкой `next_slide`. Например, `slide_18` ведёт к `slide_19`. Чтобы вставить видео между ними, меняются только эти ссылки, как показано ниже.

## Как заменить картинку

1. Положите новую PNG-картинку в `demo_001/lesson-images`.
2. Найдите нужный шаг, например `slide_19`.
3. Замените только имя файла:

```json
"image": "lesson-images/slide-19-new.png"
```

4. Запустите `npm run validate-lessons`.

## Как добавить картинку и новый слайд

Скопируйте любой простой блок, вставьте его между соседними блоками и измените `id`, текст и файл:

```json
{
  "id": "my_new_slide",
  "order": 190,
  "type": "slide",
  "src": "lesson-images/my-new-picture.png",
  "target_phrase": "Look at Iceland!",
  "native_explanation": "Посмотри на Исландию.",
  "ai_instruction": "Say one short cheerful sentence."
}
```

Затем свяжите соседние шаги через `next_slide`, если в этом уроке они используются.

## Как удалить слайд

1. Найдите весь блок от `{` до соответствующей `}`.
2. Посмотрите, какой шаг ведёт на него через `next_slide`.
3. В предыдущем шаге укажите следующий оставшийся шаг.
4. Удалите блок и лишнюю запятую.
5. Запустите проверку.

Пример: если было `slide_18 → my_new_slide → slide_19`, после удаления сделайте `slide_18 → slide_19`.

## Как поменять два слайда местами

В простом новом уроке без `next_slide` поменяйте их значения `order`. Меньшее число показывается раньше.

В текущем `demo_001` поменяйте ссылки `next_slide`, чтобы получилась нужная цепочка. Проверка сообщит, если ссылка ведёт на несуществующий шаг.

## Как дублировать слайд

Скопируйте весь блок. У копии обязательно измените:

- `slide_id` или `id`;
- `order`;
- `next_slide`, если он есть.

Картинка и текст могут остаться теми же.

## Как добавить видео перед `slide_19`

1. Положите MP4 в `DOME_77/content/lessons/demo_001/videos`, например `mila-intro.mp4`.
2. У `slide_18` замените `"next_slide": "slide_19"` на:

```json
"next_slide": "video_before_slide_19"
```

3. Вставьте отдельный блок видео:

```json
{
  "id": "video_before_slide_19",
  "order": 185,
  "type": "video",
  "src": "videos/mila-intro.mp4",
  "autoplay": true,
  "autoContinue": true,
  "skippable": true,
  "replay": true,
  "aspect_ratio": "16:9",
  "next_slide": "slide_19"
}
```

Для вертикального видео поставьте `"aspect_ratio": "9:16"`. Внешнее видео разрешено только по безопасному адресу `https://...`.

`autoplay` — начать автоматически. `autoContinue` — перейти дальше после конца. `skippable` — показать «Пропустить». `replay` — показать «Ещё раз». Необязательная картинка до загрузки видео: `"poster": "lesson-images/video-poster.png"`.

## Как удалить или заменить видео

Для замены положите новый MP4 в `videos` и измените строку `src`.

Для удаления блока `video_before_slide_19` снова направьте `slide_18` прямо на `slide_19`, затем удалите весь блок видео. Сам файл MP4 можно оставить — он не мешает уроку.

## Как изменить реплику ИИ и объяснение

В существующем шаге можно менять:

```json
"bot_says_target": "What did Mila bring you?",
"bot_explains_native": "Что Мила тебе принесла?"
```

В новом коротком формате то же самое выглядит так:

```json
"target_phrase": "What did Mila bring you?",
"native_explanation": "Что Мила тебе принесла?",
"ai_instruction": "Ask one short question and react to the child's meaning."
```

## Как изменить задание

Меняется поле `type`. Простые типы:

- `slide` — картинка/объяснение;
- `ai_dialogue` — короткий диалог;
- `voice_answer` — голосовой ответ;
- `choice` — выбор;
- `drag_drop` — перетаскивание;
- `animal_description` — описание животного;
- `break` — отдых;
- `activity` — физическое действие;
- `video` — видео.

Для голосового ответа добавьте `target_phrase` и `ai_instruction`. Для выбора добавьте `options`. Для drag/drop добавьте `items` и `targets`; у предмета `target_id` должен совпадать с `id` одной цели.

## Как управлять кнопками и подсказкой

В новый шаг можно добавить:

```json
"controls": {
  "answer": {"enabled": true, "required": true},
  "continue": {"when": "complete"},
  "hint": {"enabled": true},
  "follow_up": {"enabled": true}
}
```

`answer.enabled: false` скрывает голосовой ответ. `hint.enabled: false` отключает подсказку. `follow_up.enabled: true` разрешает один естественный дополнительный вопрос.

## Как скопировать урок и создать новый

1. Скопируйте всю папку `demo_001`.
2. Назовите копию, например `iceland_002`.
3. В новом `lesson.json` измените `lesson_id` на `iceland_002` и название `title`.
4. Укажите новый свободный `order` урока.
5. Удалите ненужные шаги и файлы, затем добавьте свои.
6. Запустите `npm run validate-lessons`.

Пока новый урок не готов, поставьте `"status": "draft"` и `"active": false`. Для публикации после успешной проверки поставьте `"status": "published"` и `"active": true`.
