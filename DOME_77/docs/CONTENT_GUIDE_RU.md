# DOME Pilot Edition — как добавлять уроки без изменения Python-кода

## 1. Три курса

- `conversation` — Разговорная практика
- `learn_to_read` — Учимся читать
- `reading` — Читаем и понимаем

Файлы курсов лежат в `content/courses/`.

## 2. Как добавить новый урок

1. Откройте `content/templates/pilot_lesson_template/`.
2. Скопируйте всю папку в `content/lessons/`.
3. Назовите новую папку, например `conversation_002`.
4. Откройте `lesson.json` в Блокноте или прямо в GitHub.
5. Измените:
   - `lesson_id` — должен совпадать с именем папки;
   - `course_id` — один из трёх ID выше;
   - `order` — номер урока в курсе;
   - `title` — название;
   - `active` — `true`, когда урок готов детям.
6. Добавьте изображения в `images/`, видео в `video/`, аудио в `audio/`.
7. В шагах указывайте относительный путь, например `images/forest.jpg`.
8. Отредактируйте `homework.json` для домашнего задания.
9. Сделайте Commit в GitHub. После Railway deploy бот сам увидит активный урок.

**Не нужно вручную добавлять Lesson 6 в Python.** Бот сам находит активные уроки по `course_id` и сортирует их по `order`.

## 3. Поддерживаемые типы заданий Pilot Edition

### Обычный экран / объяснение
`"type": "passive"`

### Один правильный ответ
`"type": "choice"`

Поля:
- `options` — варианты;
- `correct_option_index` — индекс правильного ответа, начиная с 0.

### Memory
`"type": "memory"`

Поля `items` и `targets` должны содержать пары в одинаковом порядке.

### Drag & Drop
`"type": "drag_drop"`

Также используются `items` и `targets`.

### Выбрать нужные предметы
`"type": "visual_pack"`

Поля:
- `items`;
- `correct_indices`.

### Голосовой ответ
`"type": "voice_answer"`

Поля:
- `prompt`;
- `accepted_meaning` — допустимые смыслы ответа;
- при необходимости `target_phrase`.

### Ролевая реплика
`"type": "roleplay"`

Работает как голосовой ответ, но формулируется как ситуация/диалог.

### Видео
`"type": "video"`

Для собственного файла:
`"video_file": "video/name.mp4"`

### Рисунок
`"type": "drawing"`

Ребёнок отправляет фотографию/изображение результата.

### Простая мини-игра
`"type": "mini_game"`

В Pilot Edition работает как выбор из вариантов.

## 4. Картинки

У шага можно указать:

```json
"image_file": "images/cat.jpg"
```

Если локальная картинка не указана, движок может использовать существующую генерацию иллюстраций по описанию.

## 5. Порядок уроков

Порядок задаётся полем `order`:

```json
"course_id": "reading",
"order": 6
```

После завершения предыдущего урока кнопка **▶ Продолжить** автоматически ведёт к следующему активному уроку этого курса.

## 6. Как скрыть урок

Поставьте:

```json
"active": false
```

Урок останется в GitHub, но не попадёт в последовательность.

## 7. Домашнее задание

Домашка лежит рядом с уроком в `homework.json` и использует те же типы шагов. После завершения урока она запускается автоматически. После её завершения следующий урок становится следующим в очереди.

## 8. Как выдать организации 30-дневный пилот

Откройте `config/pilots.json` и скопируйте шаблон объекта.

Пример:

```json
{
  "code": "SCHOOL30",
  "organization": "School Name",
  "active": true,
  "duration_days": 30,
  "max_children": 15,
  "courses": ["conversation", "learn_to_read", "reading"]
}
```

Родитель открывает **🎟 Доступ / промокод**, вводит `SCHOOL30`, после чего ребёнку открываются указанные курсы на 30 дней.

Чтобы остановить набор, поставьте `active: false`.

## 9. Что не менять

Не редактируйте Python-файлы ради нового урока. Для контента используются только папки в `content/lessons/`, файлы курса и `config/pilots.json`.
