# Как самостоятельно заменить базовое видео мультфильма

Для каждого урока путь к базовому видео задаётся в файле:

`content/lessons/<lesson_id>/lesson.json`

Поле:

```json
"cartoon_base": "cartoon-base.mp4"
```

## Самый простой способ

1. Откройте папку нужного урока, например:
   `content/lessons/demo_001/`
2. Замените файл `cartoon-base.mp4` новым MP4 с тем же именем.
3. Если длительность и расположение сцен остались прежними, больше ничего менять не нужно.

## Если хотите использовать другое имя файла

Положите видео в папку урока и измените только `cartoon_base`, например:

```json
"cartoon_base": "my-new-cartoon.mp4"
```

Код бота менять не требуется.

## Если изменились секунды сцен

Отредактируйте `content/lessons/<lesson_id>/timeline.json`.
Там для каждого появления героя задаются `visible_start`, `talk_start`, `end`, а в `character_animation.description_ru` можно обычным русским языком описать движение и положение героя относительно объектов кадра.

Если базовое видео отсутствует, сборщик не падает молча: он выдаёт понятную ошибку о том, какой файл не найден.
