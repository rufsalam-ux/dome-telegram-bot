# DOME — чек-лист перед продажей 30-дневного пилота

1. Создать код клиента в `config/pilots.json`.
2. Указать организацию, 30 дней, лимит детей и курсы.
3. Проверить, что нужные уроки имеют `active: true`.
4. Проверить `order` всех уроков по каждому курсу.
5. Сделать GitHub commit и дождаться Railway Online.
6. Тестовым аккаунтом родителя ввести промокод.
7. Проверить меню ребёнка: Продолжить / Мои курсы / Мои успехи.
8. Запустить первый урок и выйти на середине; проверить возврат через Продолжить.
9. Завершить урок; проверить автоматический запуск домашки.
10. Завершить домашку; проверить, что следующим предлагается следующий урок.
11. Проверить прогресс родителя.
12. Только после этого передать код организации.
