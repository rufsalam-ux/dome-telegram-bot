# DOME MVP v10 — общий пакет исправлений

## Что реально реализовано

- Удалены повторяющиеся вопросы в начале урока.
- Все экранные инструкции озвучиваются на изучаемом языке и, при необходимости, на языке ребёнка.
- Слайд 9: ребёнок выбирает одну карточку; бот проходит только вопросы выбранной карточки и пропускает остальные карточки.
- Практические ответы можно записывать до 60 секунд; ограничение 5 секунд применяется только к репликам мультфильма.
- Практические аудиофайлы удаляются после оценки; сохраняются только метаданные и финальные реплики мультфильма.
- Слайд 16: ребёнок нажимает картинку, бот называет объект на двух языках.
- Слайд 19: сначала вопрос про погоду, затем объяснение про Мадагаскар и одежду Лёши, после чего записывается обязательная реплика мультфильма.
- Слайды 21, 22, 24, 32–39, 41 и 49 переписаны по новому сценарию.
- Сбор чемодана работает как Mini App с drag-and-drop, звёздами, звуками и произнесением названия предмета.
- Добавлены кнопки «Помощь» и «Пропустить задание». Обязательные реплики мультфильма пропустить нельзя.
- На слайдах 32–38 ребёнок нажимает предмет, бот произносит слово и просит повторить; для более высокого уровня добавляется усложнение.
- Сложность продолжает адаптироваться после каждого ответа и может снижаться, если ребёнку трудно.
- Слайд 41 не ждёт ответа.
- Слайд 49: выбор настроения, озвучивание названия эмоции и повторение ребёнком.
- Реплика мультфильма длительностью до 12 секунд автоматически ускоряется до 5 секунд без изменения высоты голоса.
- Исправлена высота героя в первой сцене мультфильма.
- Добавлена библиотека повторно используемых профилей анимации и зеркальное использование прохода справа/слева.
- Голос ребёнка нормализуется примерно до -16 LUFS, фон приглушается во время речи.

## Честное ограничение анимации

В v10 используется улучшенная анимация цельного PNG: вход, проход, остановка, лёгкий поворот, шаговый ритм, зеркальное направление и исчезновение. Полноценная AI-генерация новых видеоанимаций по промпту и 2D-скелетная анимация частей тела в этот ZIP не входят. Для них добавлена совместимая библиотека профилей, куда позже можно сохранять сгенерированные клипы.

## Замена версии

1. Остановить текущую версию:

```powershell
docker compose down
```

2. Если старый контейнер остался:

```powershell
docker rm -f dome-bot
```

3. Перенести в папку v10:

- `.env`
- папку `storage`

4. Запустить:

```powershell
docker compose up --build
```

Успешный запуск содержит строку:

```text
DOME v10 starting
Polling started. Bot is ready.
```
