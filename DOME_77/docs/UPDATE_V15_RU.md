# DOME v15 — исправления урока, продолжения, согласий и оплаты

## Что исправлено

- Слайд 9 теперь является блокирующим: бот не может перейти дальше, пока ребёнок не выберет одну карточку и не ответит на все вопросы этой карточки.
- На слайде 9 нет кнопки пропуска.
- Слайды 32–39 физически отсутствуют в конфигурации урока. После исходного слайда 31 сразу открывается исходный слайд 40.
- Старые незавершённые сессии корректно переводятся на новую нумерацию.
- Кнопка «Продолжить урок» открывает последнюю незавершённую сессию и сохранённый шаг. Она не создаёт новое прохождение.
- Обязательные реплики мультфильма, включая «Я возьму с собой…», нельзя пропустить.
- Распознавание сначала использует автоматическое определение языка; принудительные языковые подсказки применяются только как резервные варианты.
- При технической неопределённости бот предлагает фразу по теме текущего задания, а не повторяет случайно услышанный текст.
- Герой в первой сцене поднят выше.
- Согласие на запись голоса обязательно подтверждается SMS до начала урока, даже если оплаты нет.
- Перед переходом к оплате отдельно подтверждается соглашение об оплате по SMS.

## Куда внести данные для получения денег

Банковские реквизиты **не вводятся в код бота**. Сначала создайте аккаунт у платёжного провайдера, например Stripe, ЮKassa или другого доступного вам сервиса, и подключите свой банковский счёт в его кабинете. Там же создайте hosted checkout/payment links для каждого тарифа.

Полученные ссылки вставьте в `.env`:

```env
PAYMENT_URL_TRIAL=https://...
PAYMENT_URL_GROUP=https://...
PAYMENT_URL_INDIVIDUAL=https://...
```

Деньги поступают в ваш аккаунт у платёжного провайдера и затем выводятся на банковский счёт, который вы привязали в кабинете провайдера. Бот не принимает и не хранит полные данные карты.

## SMS-подтверждение

Для реальной отправки SMS заполните:

```env
TWILIO_ACCOUNT_SID=
TWILIO_AUTH_TOKEN=
TWILIO_FROM_PHONE=
CONSENT_HASH_SECRET=длинная-случайная-строка
```

Технические шаблоны согласий необходимо проверить у юриста для стран, где продаётся услуга и находятся дети.

## Обновление

1. Остановите старую версию:

```powershell
docker compose down
```

2. Распакуйте v15 в новую папку.
3. Перенесите из старой папки `.env` и каталог `storage`.
4. Запустите:

```powershell
docker compose up --build
```

В журнале должна появиться строка `DOME v15 starting`.
