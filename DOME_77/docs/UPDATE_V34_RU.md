
# DOME v34 — домашнее задание после каждого урока

Добавлено:
- после завершения каждого прохождения урока бот создаёт короткое **необязательное** домашнее задание;
- задание строится по реальным данным урока и голосовым попыткам; при доступном OpenAI используется AI, при недоступности — безопасный шаблон;
- домашнее задание приходит в Telegram-бот;
- если email родителя настроен, итог урока и домашнее задание уходят на email;
- кнопки: **Выполнить сейчас / Сделать позже / Пропустить / Архив**;
- `Пропустить` не снижает прогресс и не блокирует следующий урок;
- даже пропущенное задание остаётся в архиве;
- настройки вынесены в `config/homework.json`.

## Важное ограничение Lesson Builder
В проекте есть компьютерный Lesson Builder: он позволяет создавать курс/урок, загружать слайды, вводить инструкции и выбирать тип активности.
Однако v34 **ещё не делает все типы заданий полностью универсальными в Telegram runtime**. Реально подключённые универсальные рендереры сейчас ограничены: голос, базовый AI-диалог, tap/select, drag/drop и отдельные Mini App механики. Типы `draw`, handwriting, camera, matching, sorting, puzzle и другие уже описаны в реестре и доступны для проектирования урока, но для каждого ещё нужен универсальный runtime renderer, прежде чем можно будет обещать, что любой созданный в Builder урок автоматически полностью проводится ботом без кода.
