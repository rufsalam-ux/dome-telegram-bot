# DOME v36 — исправление блокировки пассивных слайдов

Исправлено глобальное правило Course Flow Engine:

- пассивные слайды с `answer_mode: none` больше не блокируются сообщением «Сначала ответь на вопрос бота»;
- ожидание ответа включается только у activity, которая явно требует взаимодействия;
- старый `question` в данных пассивного слайда сам по себе больше не считается причиной ждать ответ;
- AI follow-up привязан к конкретному слайду через `followup_slide_id`;
- при переходе на пассивный экран устаревший follow-up автоматически очищается;
- slide_22 и slide_23 первого урока явно помечены `expects_answer: false`; у slide_22 удалён устаревший вопрос.

Ожидаемое поведение slide_22: показать/озвучить факт → кнопка «Дальше» работает сразу.
