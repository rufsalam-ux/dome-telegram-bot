# DOME v37

Добавлено:
- свободная тема: генератор 18–25 экранов (по умолчанию 21);
- тестовая кнопка пропуска оплаты свободного урока;
- архитектура одноразовой привязки карты + SMS-подтверждения последующих пакетов;
- защита от многократного Skip, пока один переход ещё обрабатывается;
- первая сцена героя в мультфильме не короче 8 секунд;
- конфигурация дополнительных героев и 2–4 диалоговых сцен;
- настройки free_topic/cartoon/payments доступны через общую систему config и API Control Center.

Ограничение анимации: независимые движения рук/ног и полноценный lip-sync требуют сегментированного персонажа или рига. Из одного PNG невозможно корректно получить настоящую скелетную анимацию без отдельной подготовки персонажа.

Свободный урок уже создаёт структуру и проигрывает базовые этапы. Для универсальных drag/drop, рисования и видео всё ещё нужен соответствующий универсальный Mini App исполнитель или прикреплённые материалы конкретного задания.
