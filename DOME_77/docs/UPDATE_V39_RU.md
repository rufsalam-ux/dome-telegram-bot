# DOME v39

Исправления свободного урока после полевого теста v38:

- генератору запрещены `item 1`, `picture 1`, пустые A/B/C и одинаковые общие формулировки;
- каждый этап получает отдельный scene/image prompt и короткое пояснение на языке ребёнка;
- обязательные 5 реплик мультфильма получают конкретный `target_phrase`;
- голос свободного урока теперь проходит STT + оценку языка/смысла; шум, другой язык и нерелевантный ответ не принимаются как `✅ Принято`;
- при ошибке есть повтор/подсказка; после принятого ответа следующий экран отправляется автоматически;
- старые Next/Skip привязаны к номеру этапа и не могут сдвинуть новый экран;
- Mini App drag/memory использует реальные `items/targets`, проверяет пары и показывает иллюстрацию текущей сцены;
- видео-этап теперь отправляет реальный короткий MP4, собранный из текущей иллюстрации, если отдельное одобренное видео не подключено;
- FFmpeg-путь мультфильма переписан: сначала отдельные MP4-сегменты, затем concat; технический stderr ребёнку не показывается;
- в мультфильме может появляться дополнительный персонаж из каталога и его TTS-реплики;
- один купленный свободный урок: максимум 3 прохождения; мультфильм на 1-м и 2-м прохождении, если суммарный бюджет двух мультфильмов не превышает $5; 3-е прохождение без нового мультфильма;
- добавлена кнопка повторного прохождения;
- Lesson Builder получил общую инструкцию к уроку;
- добавлена подробная инструкция `HOW_TO_ADD_NEXT_LESSONS_RU.md` и `publish_lessons_windows.bat`.

Примечание по стоимости: API провайдера не возвращает в текущий код подтверждённую стоимость рендера каждого MP4 как единый billing event, поэтому v39 использует консервативную настраиваемую оценку `estimated_cartoon_cost_usd` и лимит `max_two_cartoons_cost_usd=5.0`. Это бюджетный предохранитель, а не банковская выписка.
