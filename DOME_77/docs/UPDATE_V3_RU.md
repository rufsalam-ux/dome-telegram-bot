# Обновление V3

В этой версии:

- все готовые герои показываются вместе, без деления по полу;
- ребёнок выбирает героя нажатием;
- готового героя можно менять через меню;
- собственный рисунок не заменяется готовым героем случайно;
- язык меню и объяснений можно менять через меню;
- изучаемый язык можно менять через меню;
- меню переведено на русский, английский, испанский, немецкий, французский, итальянский, португальский, турецкий, арабский и китайский;
- бот произносит фразу на изучаемом языке и объяснение на языке ребёнка;
- первый мультфильм использует 10 обязательных реплик длительностью до 5 секунд.

## Как обновить уже запущенный проект

1. Останови старого бота в PowerShell: `Ctrl + C`.
2. Сохрани старый файл `.env` отдельно. В нём находятся секретные ключи.
3. Распакуй новую версию в новую папку.
4. Скопируй свой старый `.env` в новую папку рядом с `docker-compose.yml`.
5. Добавь в `.env строку с OpenAI-ключом:

```env
OPENAI_API_KEY=твой_ключ_OpenAI
OPENAI_TEXT_MODEL=gpt-5-mini
OPENAI_TTS_MODEL=gpt-4o-mini-tts
OPENAI_TTS_VOICE=coral
```

6. Открой PowerShell в новой папке и выполни:

```powershell
docker compose down
docker compose up --build
```

## Важно

Без `OPENAI_API_KEY` бот продолжит работать, но не сможет говорить голосом и переводить задания на выбранные языки.
