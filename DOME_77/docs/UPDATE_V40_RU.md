# DOME v40 — загрузка уроков с компьютера + порядок + сезонность

## Что добавлено

- Конструктор уроков в браузере с компьютера: `start_dome_control_center_windows.bat` → **📚 Открыть конструктор курсов, уроков и ДЗ**.
- Для каждого урока можно загрузить слайды PNG/JPG, написать инструкцию боту, фразу/вопрос на изучаемом языке, пояснение на языке ребёнка, тип задания, обязательность и фразу для мультфильма.
- Можно загрузить базовый MP4 финального мультфильма.
- Есть таблица таймлайна героя ребёнка: начало появления, начало речи, конец, X, Y, высота, движение и ID обязательной реплики.
- При сохранении нового урока Builder создаёт и `manifest.json`, и рабочий `lesson.json`, чтобы бот мог использовать урок без ручного редактирования JSON.
- В курсе задаётся общий порядок уроков. Бот выбирает следующий ещё не пройденный урок по этому порядку.
- Сезонные приоритеты: лето 01.06–31.08, Halloween 17.10–03.11, зима/Новый год 01.12–28.02. Если активные сезонные уроки закончились, бот возвращается к первому ещё не пройденному уроку общего порядка.
- В Control Center существующий переключатель **«Уроки по интересам»** теперь влияет и на детское меню: при `disabled` кнопка скрывается и запуск блокируется.
- Сохранены исправления свободного урока v39: проверка речи/языка, автоматический переход после ответа, защита от старых кнопок, максимум 3 прохождения; мультфильм на 1-м и 2-м прохождении только если суммарный лимит двух мультфильмов не превышает $5.

## Как открыть конструктор

1. В папке проекта дважды нажмите `start_dome_control_center_windows.bat`.
2. Откроется `http://127.0.0.1:8766/`.
3. Нажмите **📚 Открыть конструктор курсов, уроков и ДЗ**.

## Как добавить новый урок

1. Создайте/выберите курс.
2. Укажите ID урока, например `lesson_002`, название и изучаемый язык.
3. Нажмите **Создать / открыть урок**.
4. Загрузите изображения слайдов. Лучше именовать `001.png`, `002.png`, `003.png` — Builder сортирует их по имени.
5. Для каждого экрана заполните:
   - тип задания;
   - инструкцию боту;
   - фразу/вопрос на изучаемом языке;
   - пояснение на языке ребёнка;
   - варианты/объекты через `|`;
   - отметку «Обязательно»;
   - если реплика нужна в мультфильме — заполните поле «Обязательная фраза для мультфильма».
6. Загрузите базовый MP4 мультфильма.
7. В блоке «Появления героя ребёнка» добавьте интервалы и координаты.
8. Нажмите **Сохранить урок и ДЗ**.

## Порядок и сезоны

В верхней части Builder есть блок **«Порядок уроков и сезонные темы»**.

- Общий порядок: `lesson_001, lesson_002, lesson_003, ...`
- Лето: укажите только ID летних уроков.
- Halloween: укажите только ID Halloween-уроков.
- Зима/Новый год: укажите только ID зимних и новогодних уроков.

Нажмите **Сохранить порядок и сезоны**.

## Таймлайн героя

Для каждого появления героя задаются:

- `Начало, сек` — когда герой появляется;
- `Начало речи, сек` — когда должна начаться детская реплика;
- `Конец, сек` — когда герой исчезает;
- `X`, `Y` — координаты верхнего левого угла героя;
- `Высота героя, px` — масштаб;
- `Движение` — стоит/выходит слева/идёт вправо/идёт влево;
- `ID обязательной фразы` — связывает момент в мультфильме с записанной на уроке репликой.

Первая сцена героя по умолчанию — 8 секунд.

## Важно

Builder поддерживает без ручного кода базовые экраны, голосовые задания, выбор, tap/select и data-driven drag-and-drop/Memory через Mini App. Механики, помеченные в списке как «ещё не исполняется», можно описать в уроке, но они требуют отдельной реализации движка перед использованием у детей.
