# DOME v43

Ключевые исправления и расширения:

- Слайд 19 demo_001: реплика `lesha_clothes` теперь обязательная, без Skip.
- Memory внутри урока использует нормальную механику закрытых карточек: открыть две, совпадение остаётся, ошибка закрывается обратно; завершение только после всех пар.
- Builder хранит реальные пары, а технические `item 1 / meaning A` не нужны.
- Animation Library редактируется с компьютера через Lesson Builder: имя движения, направление, речь/lip-sync, взгляд, текстовое описание и готовый asset/cache key.
- Типовые движения переиспользуются. Сам факт сохранения профиля не является генерацией полноценного скелетного рига; готовый AI/rig asset можно подключить к профилю.
- Финальный титр мультфильма уменьшен до компактного safe-area lower-third и автоматически подбирает размер имени.
- Payment Adapter отделён от уроков. Конфигурация предусматривает custom / UniPAY / PayPal / Stripe, токенизированную карту, SMS-подтверждение будущих пакетов и серверную проверку entitlement. Конкретный API провайдера всё равно подключается отдельным adapter-классом.
- Course Builder хранит рекомендуемые следующие и параллельные курсы, при этом родителю можно оставить свободный выбор курса.
- Порядок уроков и сезонное чередование из предыдущей версии сохранены.

## Важно
Lesson Builder управляет данными уроков без изменения Python для уже поддерживаемых механик. Новая механика движка или новый платёжный API всё ещё требуют программного адаптера.
