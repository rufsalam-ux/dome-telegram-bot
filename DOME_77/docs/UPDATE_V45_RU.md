# DOME v45

Исправления по последним тестам:
- в регистрации добавлен вопрос, умеет ли ребёнок читать на изучаемом языке;
- уроки по интересам учитывают этот параметр;
- 5-й этап свободного/интерес-урока стал визуальным drag-and-drop по принципу чемодана: ребёнок работает с картинками, а не обязан читать;
- Mini App автоматически отправляет результат сразу после правильного выполнения, без обязательного второго нажатия «Готово»;
- повторная тема для того же ребёнка получает новый вариант, а другим детям может переиспользоваться кэшированный готовый вариант;
- первое появление героя в free-topic мультфильме удерживается минимум 9 секунд;
- детская TTS по умолчанию переключена на Coral, с тёплой эмоциональной инструкцией;
- сохранены обязательные непропускаемые реплики и автоматическое продолжение после ответов.
