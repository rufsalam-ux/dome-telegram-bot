# DOME v47 — Исландия и обновлённые механики

- Гренландия заменена на Исландию во всём активном уроке и Mini App.
- Слайды знакомства с холодной страной заменены на новые изображения Исландии пользователя.
- Чемодан теперь задача на правильный выбор для прохладной/ветреной погоды; есть подходящие и неподходящие вещи.
- Добавлены механики угадывания животных по признакам и сравнения пингвина с попугаем.
- Финал изменён на персональную историю путешествия: куда ребёнок хочет поехать, погода, вещи, кого увидеть, что делать.
- Старые неиспользуемые изображения 32–39 физически удалены.
