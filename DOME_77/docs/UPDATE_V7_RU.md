# DOME MVP v7 — что реализовано

Основа: рабочая версия `bilingua_bot_mvp_v3`, дополненная функциями, согласованными в чате.

## Реализовано в коде

1. **Все 49 слайдов первого урока** проходят по порядку.
2. **Первый слайд — голосовой диагностический диалог**: приветствие, вопрос о делах и настроении.
3. **Адаптация после каждого ответа**: понимание, грамматика, словарь, произношение, беглость и самостоятельность обновляют рабочую сложность следующего задания.
4. Уровни `PRE_A1`, `A1`, `A2`, `B1`, `B2`. Официальный уровень не меняется по одному ответу — требуется серия ответов.
5. **Проверка неверного языка**, грамматики, смысла и произношения; техническая неопределённость не считается ошибкой.
6. До **трёх исправлений**, затем одна упрощённая фраза.
7. **Текст на слайдах локализуется**: исходная надпись закрывается светлой скруглённой подложкой, поверх печатается перевод на изучаемом языке. Результат кэшируется.
8. **Сбор чемодана через Telegram Mini App**: drag-and-drop/нажатие, звёзды, короткие звуки успеха и ошибки, фанфары и haptic feedback. После интерактива ребёнок произносит «Я возьму с собой…».
9. **Уровень и прогресс** хранятся отдельно у каждого ребёнка. Команда `/progress` показывает показатели.
10. **Email родителя** задаётся командой `/set_email`. После завершения урока бот формирует и отправляет отчёт, если SMTP настроен.
11. Сохраняются старые профили: SQLite-миграции добавляют новые поля без удаления прогресса, героев и мультфильмов.
12. `/menu` и `/reset_session` работают для старых пользователей.
13. Единый каталог героев без деления по полу; собственные рисунки и каталог имеют типы `CHILD_DRAWING` и `BOT_CATALOG`.
14. OpenAI TTS кэшируется по тексту, языку, голосу и модели.
15. Детский голос обрабатывается: high-pass, шумоподавление, компрессия, лимитер, около `-16 LUFS`, пик около `-1 dBTP`; фон приглушается во время реплики.
16. Видеооснова: `-1809727758700994847(3).mp4`, 910×512, 30 fps, 99.7 секунды. Референс координат сохранён отдельно.
17. Таймлайн содержит 10 обязательных сцен на 21, 39, 55, 64, 69, 74, 79, 85, 90 и 95 секундах.
18. Windows-скрипт удаляет известные старые контейнеры перед запуском и выводит логи без буферизации.

## Честное ограничение анимации

В этой версии используется улучшенный **whole-character fallback**: вход из нужного края, движение влево/вправо, остановка, разговор, шаговый ритм, небольшой наклон и исчезновение. Это не полноценная скелетная анимация отдельных рук и ног.

Для настоящего `2D cutout/simple rig` нужен отдельный рисунок по частям или подтверждённое AI-разделение героя на голову, корпус, руки и ноги. Архитектура предусматривает следующий этап, но v7 не выдаёт fallback за готовый скелетный rig.

## Что нужно заполнить в `.env`

Обязательно:

```env
BOT_TOKEN=...
OPENAI_API_KEY=...
```

Для Mini App нужен публичный HTTPS-адрес:

```env
WEBAPP_BASE_URL=https://ваш-домен
WEBAPP_PORT=8080
```

Локальный `http://localhost:8080` открывается на компьютере, но Telegram на телефоне требует публичный HTTPS URL.

Для email-отчётов:

```env
SMTP_HOST=smtp.example.com
SMTP_PORT=587
SMTP_USERNAME=...
SMTP_PASSWORD=...
SMTP_FROM_EMAIL=reports@example.com
SMTP_STARTTLS=true
```

## Замена старой версии

1. Остановить старый бот.
2. Скопировать из старой папки файл `.env` и папку `storage`.
3. Распаковать v7 в новую папку.
4. Поместить `.env` и `storage` в корень v7.
5. Запустить `start_dome_windows.bat`.
6. В Telegram отправить `/reset_session`, затем `/menu`.
