# DOME MVP v9 — исправление речи и привязки карты

## Исправлено

- Устранён бесконечный цикл сообщения «Я не уверена, что правильно расслышала запись».
- Добавлен резервный speech-to-text через `whisper-1`, если основной транскрипционный модуль не отвечает.
- Добавлен резервный анализ ответа через `gpt-4o-mini`, если основной текстовый model недоступен.
- Технические ошибки распознавания не считаются ошибками ребёнка.
- После двух технически нераспознанных записей бот сохраняет лучший вариант и продолжает урок, чтобы ребёнок не застревал.
- Для учебных ошибок действует протокол: максимум 3 исправления → 1 упрощённая фраза → следующая запись сохраняется как лучший вариант.
- Ответ на родном языке считается учебным исправлением и бот просит повторить на изучаемом языке.
- После принятого ответа бот даёт короткую реакцию, соответствующую смыслу ответа ребёнка.
- Добавлена кнопка «Привязать карту» в постоянное меню.
- После выбора героя показывается экран привязки карты с временной кнопкой «Пропустить пока».
- Для реальной привязки добавьте безопасную HTTPS-ссылку в `.env`: `PAYMENT_URL=https://...`.

## Замена версии

1. Остановите текущую версию: `docker compose down`.
2. Распакуйте новый ZIP в отдельную папку.
3. Скопируйте из старой папки `.env` и папку `storage`.
4. Добавьте в `.env` строку `PAYMENT_URL=` либо HTTPS-ссылку платёжного провайдера.
5. Запустите: `docker compose up --build`.

При запуске должна появиться строка `DOME v9 starting`.
