DOME MOBILE 77

Это цельная мобильная версия, согласованная с backend DOME_77.
В неё уже внесены standalone-регистрация/вход по email без внешней привязки,
подтверждение email, повторная отправка кода и восстановление пароля через API,
а также актуальные RootApp, LessonPlayer и mobile API.

ВАЖНО:
- .env с секретами намеренно не включён.
- Для API используйте EXPO_PUBLIC_DOME_API_BASE_URL. Пример есть в .env.example.
- Устанавливать поверх старой папки не требуется: это отдельная полная папка.
- Для локального запуска: npm install, затем npm start.
- Для APK предусмотрен скрипт npm run build:apk (требует настроенный Expo/EAS аккаунт).
