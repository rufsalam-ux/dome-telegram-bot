# DOME Mobile v3 — Bot Parity

Эта версия построена не на выдуманном демо-уроке, а на `demo_001` из DOME bot v76.

Что реально подключено на стороне приложения:
- профиль семьи и детей загружается с DOME backend через одноразовый `/mobile` код;
- нет захардкоженных Mia/8 лет;
- выбор готового героя или загрузка своего рисунка;
- реальные слайды разговорного урока из Telegram-бота;
- ведущая озвучивает каждый слайд;
- микрофон реально записывает файл; надпись «ответ записан» не появляется без записи;
- запись отправляется на backend DOME для Whisper/OpenAI-проверки;
- герой показан поверх урока;
- два отдельных прохождения;
- финальный мультфильм строится сервером из голоса и героя;
- ДЗ отправляется только после первого прохождения.

Для полной работы сначала разверните backend v77 Mobile API Bridge, затем запустите это приложение.
