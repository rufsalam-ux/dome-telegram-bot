# DOME Mobile — продукт

Одна кодовая база React Native/Expo для Android и iOS.

## Родитель
- язык интерфейса независим от языка обучения ребёнка;
- SMS + email verification;
- до 5 детей;
- отдельные Terms / Privacy / Parent / Voice&AI / Movie / recurring-payment consent;
- серверные тарифы и цены;
- подписка и checkout через backend;
- отчёты, ДЗ, мультфильмы, прогресс.

## Lesson Engine
Registry компонентов: voice, reading, choice, matching, memory, drag/drop, sorting,
sequencing, connect-lines, tracing/handwriting, drawing/coloring/maze, phonics,
word/sentence building, hotspots, video/audio, physical and creative activities.

AI-import -> карта сцен -> validation -> preview -> publish.
Обычное добавление уроков не требует новой сборки APK.
