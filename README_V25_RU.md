# DOME v25

Критические исправления:
- OpenAI Transcribe использует `response_format=json`, совместимый с `gpt-4o-mini-transcribe`.
- Слайд 24 переводится в отдельное состояние `waiting_webapp` и не может быть пропущен старой кнопкой «Дальше».
- После Mini App бот обязательно ждёт голосовую реплику `take_trip`; только затем переходит дальше.
- Любой дополнительный вопрос ставит `followup_pending` и блокирует переход до ответа.
- FFmpeg запускается в экономном режиме для Railway, без нестабильного sidechain-фильтра.
- Полная команда и stderr FFmpeg пишутся в Railway Deploy Logs.
