# DOME v29 — Universal Engine, этап 2

Эта версия продолжает v28 и делает формат уроков безопаснее для будущих обновлений.

## Добавлено

- универсальный runtime-контракт для всех типов заданий;
- явное разделение: **тип уже исполняется** / **тип сохранён в формате, но renderer появится позже**;
- миграция manifest-файлов без ручного переписывания уроков;
- валидация обязательных заданий, попыток и camera/spatial-настроек;
- правило для camera-задач относительно ребёнка: зеркальность должна определяться автоматически;
- schema 2.1;
- тесты совместимости.

## Важно

Сложные механики вроде live handwriting, pose tracking, realtime reading tracking и анализа видео не объявлены «готовыми», пока их renderer реально не реализован. Но уроки уже можно описывать этими типами — формат останется совместимым, когда renderer будет добавлен.

## Секреты

Ключи не хранятся в коде. Локально используйте `.env`, в Railway — Variables.
