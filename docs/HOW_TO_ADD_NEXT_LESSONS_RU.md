# DOME v39 — как добавлять следующие уроки без правки Python

## Главное
Новые обычные уроки нужно наполнять через **DOME Control Center / Lesson Builder**, а не создавать новый ZIP на каждый урок. ZIP нужен только когда появляется новая механика, которой движок ещё не умеет выполнять.

## 1. Открыть конструктор
На Windows открой папку DOME и дважды нажми:

`start_lesson_builder_windows.bat`

Откроется локальная страница:

`http://127.0.0.1:8766/builder`

Если окно браузера не открылось само, адрес можно вставить вручную.

## 2. Создать курс
В блоке **«1. Курс»** заполни:
- ID курса: латиницей, например `english_a1`;
- название: например `English Adventures A1`;
- цену/валюту, если они уже известны.

Нажми **«Сохранить курс»**.

## 3. Создать урок
В блоке **«2. Урок»**:
- ID урока: `english_a1_001`, `english_a1_002` и т. д.;
- название урока;
- выбери курс;
- изучаемый язык, например `en`;
- в поле **«Общая инструкция к уроку»** напиши правила, относящиеся ко всему уроку.

Пример общей инструкции:

> Урок для ребёнка 7–10 лет. Основная речь — английская, короткие пояснения — на русском. Бот ждёт ответ после каждого вопроса. После принятого ответа сам показывает следующий этап. Обязательные реплики для мультфильма нельзя пропускать. Ошибка: до 2 мягких попыток, затем упрощение. Не заставлять повторять понятный ответ.

Нажми **«Создать / открыть урок»**.

## 4. Подготовить слайды
Слайды удобнее сохранять как отдельные PNG/JPG.

Имена должны идти по порядку:

- `001.png`
- `002.png`
- `003.png`
- ...
- `049.png`

Конструктор сортирует их по имени. Поэтому обязательно использовать ведущие нули.

В блоке **«3. Слайды / материалы урока»** выбери сразу все картинки и нажми **«Загрузить слайды»**.

## 5. Что писать в инструкции к каждому слайду
У каждого экрана есть поле **«Инструкция AI: что показать/спросить/проверить?»**. Это главное поле. Пиши там поведение бота человеческим языком, максимально конкретно.

Хороший пример:

> Покажи картинку. Спроси по-английски: “What is the boy wearing?” Затем коротко поясни по-русски: «Что надето на мальчике?» Жди голосовой ответ. Допустимые ответы: “a jacket”, “He is wearing a jacket”. Если ребёнок отвечает по-русски — попроси сказать по-английски и дай пример. После понятного ответа не проси повторять, сразу переходи дальше.

Для обязательной реплики мультфильма:

> ОБЯЗАТЕЛЬНО ДЛЯ МУЛЬТФИЛЬМА. Бот произносит: “Look! I found a treasure!” Ребёнок должен записать эту фразу голосом до 5 секунд. Нельзя пропустить. Не принимать шум, ругательство, ответ на другом языке или фразу не по смыслу. До 2 мягких попыток, затем дать фразу по частям. Сохранить лучшую корректную запись в мультфильм и автоматически перейти дальше.

Для drag-and-drop:

> Открыть drag-and-drop. Слева реальные предметы: jacket, hat, boots. Справа три соответствующие картинки. Ребёнок перетаскивает каждое слово на правильную картинку. Пока всё не собрано верно, задание не завершать. После «Готово» автоматически открыть следующий экран.

Для выбора:

> На картинке три животных. Спроси: “Which animal can fly?” Кнопки: cat / bird / dog. Правильный ответ bird. При первой ошибке дать короткую подсказку и оставить тот же экран. После правильного ответа перейти дальше автоматически.

Для пассивного экрана:

> Просто покажи картинку и озвучь 1–2 короткие фразы. Ответ не нужен. Только здесь должна быть кнопка «Дальше».

## 6. Выбрать тип задания
Справа у каждого экрана выбери механику. В конструкторе типы с **✓** уже поддерживаются движком сейчас. Типы с пометкой **«позже»** пока не надо использовать как обязательные интерактивы — они требуют отдельного обновления движка.

Основные рабочие типы выбирай по смыслу: голосовой ответ, повтор фразы, AI-диалог и другие отмеченные ✓.

## 7. «Обязательно»
Поставь галочку **«Обязательно»**, если этот этап нельзя пропускать.

Обязательно ставить для:
- реплик, которые должны попасть в мультфильм;
- ключевых проверок цели урока;
- действий, без которых следующий этап не имеет смысла.

Для обычного объяснения или дополнительной тренировки галочку можно не ставить.

## 8. Домашнее задание
В блоке **«Домашнее задание к этому уроку»** включи ДЗ только если оно нужно именно этому уроку.

Можно заполнить:
- ориентировочное время;
- текст задания;
- мини-задания;
- отправлять ли в бот;
- отправлять ли родителю на email;
- можно ли отложить/пропустить.

Если ДЗ выключено, после этого урока бот ничего по ДЗ не отправляет.

## 9. Сохранить
Нажми **«Сохранить урок и ДЗ»**.

Файл урока будет сохранён в:

`content/lessons/<ID_УРОКА>/manifest.json`

Картинки урока находятся в той же папке урока.

## 10. Проверить урок до публикации
Сначала проверь:
- порядок слайдов;
- на каждом вопросе бот действительно ждёт ответ;
- после ответа новый этап приходит автоматически;
- старые кнопки предыдущих этапов не работают;
- обязательные задания нельзя пропустить;
- тексты на изучаемом и языке ребёнка соответствуют задумке;
- нужные реплики мультфильма конкретные и не длиннее ~5 секунд.

## 11. Опубликовать новые уроки в Railway
После сохранения уроков запусти в папке DOME:

`publish_lessons_windows.bat`

Скрипт добавляет в Git только `content` и `config`, делает commit и `git push origin main`. `.env` он не публикует.

Railway после push должен автоматически развернуть новую версию содержимого.

## 12. Когда нужен новый ZIP
Новый ZIP **не нужен**, если ты:
- добавляешь новый курс;
- добавляешь новый урок;
- меняешь картинки;
- меняешь инструкции;
- меняешь порядок и тип уже поддерживаемых заданий;
- добавляешь/убираешь ДЗ.

Новый ZIP нужен, если требуется новая техническая механика, которой нет в движке: например новая Mini App-игра, новый вид распознавания камеры, новая схема анимации персонажа и т. п.

## Рекомендуемый шаблон одной инструкции к заданию
Для каждого интерактивного экрана лучше указывать 7 вещей:

1. Что показать ребёнку.
2. Что сказать на изучаемом языке.
3. Что коротко пояснить на языке ребёнка.
4. Какой ответ/действие считается правильным.
5. Что делать при ошибке или другом языке.
6. Можно ли пропустить.
7. Нужно ли сохранить голос/результат для мультфильма или прогресса.
