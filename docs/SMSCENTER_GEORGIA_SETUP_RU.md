# Настройка SMSCenter Georgia для DOME v20

В v20 Twilio полностью удалён. Бот сам создаёт шестизначный OTP-код, хранит только защищённый HMAC-хеш и отправляет код через SMSCenter Georgia.

## Что нужно получить в кабинете SMSCenter

1. Дождаться активации пользователя администратором.
2. Создать и дождаться одобрения имени отправителя, например `DOME` или `BilingvaDom`.
3. Создать API-ключ.
4. При необходимости пополнить SMS-баланс.

## Что вставить в `.env`

```env
SMSCENTER_API_KEY=ваш_api_ключ
SMSCENTER_SENDER_ID=DOME
SMSCENTER_API_URL=https://sms-api.wifisher.com/api/v2/send
CONSENT_HASH_SECRET=длинная_случайная_секретная_строка_не_короче_24_символов
```

`SMSCENTER_SENDER_ID` должен в точности совпадать с одобренным именем отправителя в кабинете.

## Как работает подтверждение

1. Родитель принимает соглашение.
2. Вводит телефон в формате `+995599123456`.
3. Бот создаёт случайный шестизначный код.
4. SMSCenter отправляет код.
5. Код действует 10 минут, максимум 5 попыток.
6. В базе сохраняется факт согласия, но не сам код.

## Запуск

Перенесите из старой версии только `.env` и `storage`, затем добавьте новые переменные SMSCenter и выполните:

```powershell
docker compose down
docker compose up --build
```

В логе должна появиться строка `DOME v20 SMSCENTER GEORGIA starting`.
