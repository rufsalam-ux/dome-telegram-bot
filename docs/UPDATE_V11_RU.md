# DOME v11 — установка и новые правила

## Установка
1. Скопируйте `.env` и папку `storage` из предыдущей версии.
2. Распакуйте архив в отдельную папку.
3. Верните `.env` и `storage` в корень новой папки.
4. Запустите `start_dome_windows.bat` или выполните `docker compose up --build`.

В v11 удалено фиксированное имя контейнера, поэтому конфликт имени `dome-bot` больше не возникает. Перед запуском всё равно остановите старую версию, чтобы один BOT_TOKEN не использовали два процесса.

## Оплата: куда вставлять ссылки
Бот не хранит данные банковской карты. Он открывает безопасную страницу платёжного провайдера.

В `.env` вставьте отдельные checkout-ссылки:

```env
PAYMENT_URL_TRIAL=https://...
PAYMENT_URL_GROUP=https://...
PAYMENT_URL_INDIVIDUAL=https://...
```

Ссылки создаются в Stripe, ЮKassa, CloudPayments или другом подключённом провайдере. После выбора тарифа бот показывает соответствующую кнопку оплаты.

## Повторное прохождение
Первое завершение создаёт мультфильм. После этого урок можно пройти ещё два раза без нового мультфильма. После трёх завершений урок блокируется.

## Голос
Ограничение 5 секунд применяется только к десяти репликам мультфильма. Остальные ответы можно записывать до 60 секунд.
