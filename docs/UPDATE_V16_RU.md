# DOME v16 — исправления маршрута урока

## Изменения
- Кнопка «Продолжить урок» восстанавливает последний сохранённый шаг существующей незавершённой сессии.
- При выходе в меню текущая позиция сначала сохраняется в базе.
- Слайд 2 физически удалён из конфигурации и папки изображений; переход 1 → 3.
- Слайды 32–39 физически удалены из конфигурации и папки изображений; переход 31 → 40.
- На сцене Мадагаскара вопрос «жарко или холодно» можно пропустить, но бот затем обязательно просит записать первую мультфильмную реплику про одежду Лёши.
- Сбор чемодана на слайде 24 и реплика «Я возьму с собой…» не пропускаются даже через старую кнопку в истории чата.

## Обновление
1. Остановить текущую версию: `docker compose down`.
2. Распаковать v16 в новую папку.
3. Перенести `.env` и папку `storage` из предыдущей версии.
4. Запустить: `docker compose up --build`.

Старые незавершённые сессии автоматически переводятся на актуальную нумерацию.
