
# DOME v33 — игры, меню ребёнка/родителя, возраст

Что добавлено:

1. **Раздельное меню**
   - Главное меню теперь ведёт в две зоны: **«Ребёнку»** и **«Родителю»**.
   - В детском меню: продолжить урок, список уроков, игры, свободная тема, герой, профиль.
   - В родительском меню: прогресс, email-отчёты, языки, день рождения, оплата, поддержка, настройки.

2. **Возраст ребёнка**
   - На онбординге добавлен обязательный выбор возраста.
   - В БД добавлены поля `age_years`, `birth_day`, `birth_month`.

3. **Игры**
   - Добавлен отдельный веб-раздел `/games`.
   - Дизайн: яркие, светлые, насыщенные цвета.
   - Готовые мини-игры в каталоге:
     - Memory
     - Найди предмет
     - Быстрый выбор
     - Собери слово
     - Bingo mini
   - Список будущих игр вынесен в `config/games.json`.

4. **Свободная тема**
   - В детском меню появился отдельный вход для темы по интересам ребёнка.
   - Сейчас это подготовленная точка входа под дальнейшую AI-генерацию урока.

5. **Поддержка**
   - В родительском меню есть раздел поддержки.
   - Для работы нужно заполнить `SUPPORT_CHAT_URL` и при необходимости `SUPPORT_CALL_LABEL`.

6. **Прогресс для родителя**
   - Родитель видит более подробную сводку: количество завершённых уроков, возраст, уровень и ключевые навыки.
   - Email-отчёты можно включить прямо из меню.

Важно:
- Для кнопки игр должен быть настроен `WEBAPP_BASE_URL` или `RAILWAY_PUBLIC_DOMAIN`.
- День рождения пока отображается как подготовленная ветка — можно дополнить отдельной формой ввода дня и месяца.
