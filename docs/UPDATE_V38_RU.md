# DOME v38

Исправлен режим «Урок на свободную тему». Теперь это не текстовый прототип: урок генерирует 18–25 этапов с иллюстрациями, TTS-аудио, вариантами ответа, Mini App drag/drop и memory, пятью распределёнными по уроку обязательными голосовыми репликами для мультфильма. Обязательные реплики нельзя пропустить. Старые кнопки пропуска не могут перескочить несколько заданий.

Иллюстрации генерируются через OpenAI Images API (gpt-image-1-mini) и кэшируются; при ошибке API создаётся локальная визуальная карточка, чтобы слайд не был голым текстом.

После последнего задания бот автоматически собирает и отправляет мультфильм 60–90 секунд: использует выбранного героя ребёнка, сохранённые голосовые реплики и короткие TTS-реплики второстепенного персонажа. Фоны берутся из картинок самого урока.

Для свободного урока нужен заранее выбранный/загруженный герой. Тестовый обход оплаты сохранён.
