# DOME v41 — оплата до нового урока и чередование сезонных уроков

## Оплата
Перед созданием нового обычного урока движок проверяет активный доступ к курсу (`CourseEnrollment`). Если доступа нет, урок не запускается: бот показывает родительский экран оплаты. Для тестирования в `config/payments.json` временно включён `allow_test_course_payment_bypass=true`; тестовый пропуск создаёт доступ с источником `TEST_BYPASS`.

Реальная оплата по внешней ссылке всё ещё требует webhook/подтверждения платёжного провайдера, которое должно создать/активировать `CourseEnrollment`. Сам DOME не считает переход по ссылке успешной оплатой.

## Сезонность
У курса появился параметр `lessons_per_week` (1–14), редактируемый в Lesson Builder. Если активен сезон и `lessons_per_week > 1`, новые уроки чередуются: тематический → обычный по общему порядку → тематический → обычный. Если тематические закончились, продолжается обычная очередь; если обычные закончились, продолжаются тематические. При одном уроке в неделю сохраняется сезонный приоритет.
