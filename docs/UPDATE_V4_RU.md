# DOME MVP v4 — замена старой версии

## Перед заменой

1. Остановите старого бота: `Ctrl+C`.
2. Сохраните из старой папки:
   - `.env`;
   - папку `storage` (в ней база, профили, герои, записи и мультфильмы).
3. Не пересылайте `.env` другим людям.

## Замена

1. Распакуйте новый ZIP в отдельную папку.
2. Скопируйте старый `.env` в корень новой папки рядом с `docker-compose.yml`.
3. Скопируйте старую папку `storage` в корень новой папки с заменой пустой папки, если она существует.
4. Проверьте, что в `.env` есть:

```env
BOT_TOKEN=...
OPENAI_API_KEY=...
OPENAI_TEXT_MODEL=gpt-5-mini
OPENAI_TTS_MODEL=gpt-4o-mini-tts
OPENAI_TTS_VOICE=coral
OPENAI_TRANSCRIPTION_MODEL=gpt-4o-mini-transcribe
```

5. Запустите в новой папке:

```powershell
docker compose down
docker compose up --build
```

## Для старых пользователей

При старте выполняется SQLite-миграция. Отсутствующие языки заполняются значениями по умолчанию, а таблица голосовых попыток получает новые поля оценки.

Пользователь должен отправить `/menu`. Если старая FSM-сессия зависла, отправить:

```text
/reset_session
```

Команда закрывает только активную сессию и не удаляет профиль, героя, прогресс или старые файлы.

## Что проверять вручную

1. Старый аккаунт видит новое меню после `/menu`.
2. Урок проходит 49 настроенных шагов.
3. На обязательных шагах бот ждёт голос.
4. Ответ на другом языке вызывает исправление.
5. Ошибочная фраза получает до трёх исправлений, затем упрощённый вариант.
6. Итоговый ролик использует `content/lessons/demo_001/cartoon-base.mp4`.
7. Голос ребёнка слышен поверх приглушённого фонового звука.
