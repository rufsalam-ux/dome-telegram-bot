# DOME MVP v6 — исправление запуска

## Что исправлено

- Добавлены явные стартовые логи: теперь после запуска видно этапы `DOME bot starting`, `Database is ready`, `Connected to Telegram`, `Polling started. Bot is ready.`
- Python запускается без буферизации логов (`PYTHONUNBUFFERED=1`).
- Контейнер получил постоянное имя `dome-bot`.
- Compose-проект получил постоянное имя `dome_v6`.
- Добавлен `start_dome_windows.bat`, который перед запуском удаляет известные старые контейнеры DOME/Bilingua.
- Добавлены `check_dome_windows.bat` и `STOP_DOME_WINDOWS.bat`.
- Добавлена проверка подключения к Telegram через `get_me()` до старта polling.
- При конфликте токена теперь выводится понятное сообщение.

## Замена старой версии

1. Распакуйте архив в новую отдельную папку.
2. Скопируйте из старой версии в новую:
   - `.env`
   - папку `storage`
3. Убедитесь, что Docker Desktop запущен.
4. Дважды нажмите `start_dome_windows.bat`.

Успешный запуск выглядит так:

```text
DOME bot starting
Database is ready
Connected to Telegram as @...
Polling started. Bot is ready.
```

Окно нельзя закрывать, пока бот должен работать.

## Проверка

Запустите `check_dome_windows.bat`. Он покажет контейнер и последние логи.

## Важно

Если после автоматического удаления старых локальных контейнеров всё равно появится `Telegram conflict`, значит тот же токен работает на другом компьютере или сервере. Код не может одновременно разрешить двум процессам получать обновления одного Telegram-бота; тогда токен нужно отозвать в BotFather.
